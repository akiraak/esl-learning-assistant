# 印刷用ページ: 印刷時の文字を小さくする

## 目的・背景

管理画面の印刷用表示（printView.ts）を紙に出すと文字が大きすぎる。
本文 12pt は紙面に対して余裕があり、ページ数も無駄に増える。
印刷時のみサイズを一段下げ、書籍・配布資料でよく使われる 10.5pt を本文の既定にする。

## 対応方針

- `renderPrintPageHtml` の `@media print` 内のサイズ指定のみを変更する
  （画面表示の px 指定は据え置き。「印刷時だけ小さく」の要件をそのまま満たす）
  - `article > h1`: 16pt → 13.5pt
  - `.body p, .body li`: 12pt → 10.5pt
  - `.body h1`: 14pt → 12.5pt
  - `.body h2`: 13pt → 11.5pt
  - `.body h3`: 12.5pt → 11pt
- 行間 `line-height: 1.9` は変更しない。相対値なので行送りも文字と同じ比率で詰まる
- あわせて `@page` の `@bottom-center`（ページ番号）を 10pt → 9pt にする。
  本文より大きい／同等のノンブルは紙面で目立ちすぎるため

## 影響範囲

- backend の `src/printView.ts` のみ（共通テンプレートのため Photo OCR /
  Transcription / Document の英文・訳文すべての印刷ページに反映）
- フォント指定（Georgia + 明朝系のフォールバック）は変更しないため、
  英文・日本語の見え方の系統は今までどおり

## テスト方針

- 単体テスト: 生成 HTML の `@media print` に新しいサイズが含まれること
- 目視: Document 訳（複数ページ）を print-to-pdf し、文字が一段小さくなり
  ページ数が減ること、画面表示のサイズは変わっていないことを確認
