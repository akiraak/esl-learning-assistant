# 執筆画面のチャットで AI 側の吹き出し右に無駄な余白が残る

## 目的・背景

執筆画面（`/admin/writing/:id`）右の AI チャットで、AI の返答の右側に
常に 8% 分の空きが縦一列に残り、AI 欄を広げても本文がその分狭いままになっている。

原因は `.msg .bubble { max-width: 92%; }`。左寄せの AI 側にもこの上限がかかるため、
右端に必ず 8% の空白ができる。92% は「自分の発言は画面いっぱいにしない」ための
上限なので、右寄せのユーザー側にだけ効かせれば足りる。

## 対応方針

- `.msg .bubble` の `max-width` を `100%` にし、`92%` は `.msg-user .bubble` に移す

## 影響範囲

- `backend/src/compositionView.ts` のスタイルのみ（HTML 構造・スクリプトは変更なし）

## テスト方針

- `npm test`（既存のスナップショット的なアサーションが壊れないことの確認）
- 執筆画面を開いて、AI の返答が AI 欄の幅いっぱいに広がり、ユーザー発言は
  従来どおり右寄せで少し狭いままであることを目視確認
